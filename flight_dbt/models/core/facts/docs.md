Таблица фактов рейсов аэропортоа Пхукета (HKT)
Одна строка - один рейс (вылет или перелет).

Источники данных:
 - API AeroDataBox - оперативные данные о рейсах
 - Исторические parquet-файлы - данные за прошлые периоды

 Дедупликация выполняется по комбинации авиакомпании, номера рейса,
 времени и направления. При наличии нескольких версий одного рейса
 выбирается запись с наиболее ваежим фактическим временем.

 Задержки рассчитываются как разница между фактическим и плановым
 временем в минутах. Отрицательное значение означает ранний вылет или прилет.
